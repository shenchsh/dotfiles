# Chanson AI

Compact PopClip actions for ChatGPT.

## Actions

- **Ask ChatGPT** — answers selected requests directly; explains selected terms or passages when they are not phrased as requests.
- **Rewrite** — rewrites selected text into clear, natural, concise English.
- **Summarize** — summarizes selected text.
- **Coach** — opens the configured English Coach ChatGPT conversation and pastes the selected text into the composer.

The Coach action adds no prompt of its own.
